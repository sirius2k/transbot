## 기능 설명

입력 텍스트와 번역 결과를 한 번에 초기화하는 지우기 버튼 추가. 사용자가 새로운 번역 작업을 시작할 때 이전 내용을 빠르게 제거할 수 있도록 사용성을 개선합니다.

### 기대 효과

- 사용자가 매번 수동으로 텍스트를 삭제할 필요 없음
- 새로운 번역 작업 시작 시 워크플로우 간소화
- 직관적인 UI로 사용자 경험 향상

## 작업 내용

1. **지우기 버튼 UI 추가**
   - Streamlit 버튼 컴포넌트 추가
   - 적절한 위치 배치 (입력 영역 근처)
   - 아이콘 또는 텍스트 레이블 설정

2. **상태 초기화 로직 구현**

3. **사용자 피드백 추가**

   - 초기화 완료 확인 (선택적)

## 구현 결과

### 구현 내용

`app.py`에 지우기 버튼 기능을 추가했습니다:

1. **버튼 위치**: 입력 텍스트 영역 하단에 배치
2. **초기화 대상**:
   - `st.session_state.input_text`
   - `st.session_state.translation_result`
3. **사용자 피드백**: Streamlit의 `st.rerun()` 사용하여 즉시 UI 업데이트

### 코드 예시

```python
# 지우기 버튼
if st.button("🗑️ 지우기"):
    st.session_state.input_text = ""
    st.session_state.translation_result = ""
    st.rerun()
```
