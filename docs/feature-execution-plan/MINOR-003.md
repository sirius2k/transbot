## 기능 설명

안내 문구를 메인 화면에서 사이드바의 Help 섹션으로 이동하여 메인 화면을 더 깔끔하게 정리합니다. 사용자가 필요할 때만 도움말을 확인할 수 있도록 UI를 개선합니다.

### 기대 효과

- 메인 화면이 더 간결하고 정돈됨
- 핵심 기능에 집중할 수 있는 UI
- 도움말이 필요한 사용자만 사이드바에서 확인
- 전체적인 사용자 경험 향상

## 작업 내용

1. **사이드바에 Help 섹션 추가**
   - `st.sidebar.header()` 또는 `st.sidebar.expander()` 사용
   - "도움말" 또는 "Help" 제목 설정

2. **안내 문구 이동**
   - 메인 화면의 안내 문구 제거
   - Help 섹션으로 내용 이동
   - 필요시 내용 간소화 또는 재구성

3. **UI 레이아웃 조정**
   - 메인 화면 여백 최적화
   - 사이드바 순서 조정 (설정 → Help 순서)

## 구현 결과

### 구현 내용

`app.py`에서 안내 문구를 사이드바로 이동했습니다:

1. **메인 화면**: 안내 문구 제거
   - 입력 영역과 번역 버튼에 집중
   - 불필요한 설명 제거

2. **사이드바 Help 섹션**: 안내 문구 추가
   - `st.sidebar.expander("📖 도움말")` 사용
   - 축소 가능하여 사이드바 공간 효율적 사용
   - 기능 설명, 사용법 등 포함

### 코드 예시

```python
# 사이드바 - Help 섹션
with st.sidebar.expander("📖 도움말"):
    st.markdown("""
    ### 사용 방법
    1. 텍스트를 입력하세요
    2. 번역 버튼을 클릭하세요
    3. 결과를 확인하세요

    ### 기능
    - 자동 언어 감지
    - Markdown 포맷 보존
    - 복사 버튼 제공
    """)
```
